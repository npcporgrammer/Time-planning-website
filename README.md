# 网页日志 · Weekly Planner（日程规划表）

一个完全**本地离线**运行的周计划 / 日程规划网页应用。用纯 HTML + CSS + 原生 JavaScript 实现，无需任何后端或构建工具，双击 `index.html` 即可使用。

> 所有数据只保存在你本机浏览器（`localStorage`），不会上传到任何服务器。

## ✨ 功能

- **周视图规划**：一周七天独立时间轴，切换周、回到本周
- **日程块（Schedule Blocks）**：自定义名称与颜色，拖拽放入任意时间格
- **时间轴编辑**：按天自定义时间段与高度，支持快速生成、应用到整周
- **当日待办**：日程 + 小事清单，实时进度条
- **长期备忘**：收纳学习网址、备赛任务，按权重在顶部滚动提示
- **打卡记录**：昵称、累计打卡、连续打卡统计
- **回收站**：删除内容可还原，防误删
- **复用上周**：把上周安排带入本周，可只顺延未完成项
- **导入 / 导出备份**：JSON 格式，数据可迁移

## 🚀 快速开始

无需安装依赖，直接打开：

1. 用浏览器打开 `index.html`
2. 或本地起一个静态服务：
   ```bash
   # 任选其一
   python -m http.server 8080
   # 或
   npx serve .
   ```
   然后访问 `http://localhost:8080`

## 🛠 技术栈

- HTML5 / CSS3
- 原生 JavaScript（ES6+）
- `localStorage` 本地持久化
- 无第三方依赖

## 📅 数据范围

日程日期范围固定在 `2026-01-01` 至 `2029-12-31`。
